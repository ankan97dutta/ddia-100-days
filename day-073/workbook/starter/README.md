# Starter: Day 073

Estimate uncertainty; do not pretend clocks are exact. Tune `--offset-ms` and `--uncertainty-ms` to flip orderability.

## Run

```bash
python3 main.py --help
python3 main.py
python3 main.py --offset-ms
python3 main.py --uncertainty-ms
```

Requires Python 3.10+ (stdlib only). Creates a `data/` folder next to `main.py` when needed.
