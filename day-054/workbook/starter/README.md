# Starter: Day 054

Generate skewed traffic and observe hotspots. Compare `python3 main.py` vs `python3 main.py --salt-hot`.

## Run

```bash
python3 main.py --help
python3 main.py
python3 main.py --salt-hot
```

Requires Python 3.10+ (stdlib only). Creates a `data/` folder next to `main.py` when needed.
