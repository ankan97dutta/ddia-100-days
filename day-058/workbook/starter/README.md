# Starter: Day 058

Decide what must sit inside one transaction, and what must not. Compare `--fail-payment` with and without `--unified-tx`.

## Run

```bash
python3 main.py --help
python3 main.py
python3 main.py --fail-payment
python3 main.py --unified-tx
```

Requires Python 3.10+ (stdlib only). Creates a `data/` folder next to `main.py` when needed.
