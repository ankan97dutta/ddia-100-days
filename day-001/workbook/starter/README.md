# Starter: Day 001

Map a system you know into workloads, constraints, and the choices it made. Prints a sample architecture inventory and simulates removing one component.

## Run

```bash
python3 main.py --help
python3 main.py
python3 main.py --break redis_cache
python3 main.py --json
```

Requires Python 3.10+ (stdlib only). Creates a `data/` folder next to `main.py` when needed.
