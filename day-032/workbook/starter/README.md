# Starter: Day 032

See how column order and covering indexes change plans. See when index-only plans disappear.

## Run

```bash
python3 main.py --help
python3 main.py
python3 main.py --cover
python3 main.py --order ba --break
```

Requires Python 3.10+ (stdlib only). Creates a `data/` folder next to `main.py` when needed.
