# Starter: Day 065

Compare serial execution with concurrent serializable transactions. Compare `python3 main.py` vs `python3 main.py --serial`.

## Run

```bash
python3 main.py --help
python3 main.py
python3 main.py --serial
```

Requires Python 3.10+ (stdlib only). Creates a `data/` folder next to `main.py` when needed.
