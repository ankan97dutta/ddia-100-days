# Starter: Day 052

Partition by hash and watch key distribution. For uniform keys; `python3 main.py --skewed` for power-law frequency.

## Run

```bash
python3 main.py --help
python3 main.py
python3 main.py --skewed
```

Requires Python 3.10+ (stdlib only). Creates a `data/` folder next to `main.py` when needed.
