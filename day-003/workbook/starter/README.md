# Starter: Day 003

Trace what is authoritative vs what is derived. Lists lineage roles and simulates rebuilding (or failing to rebuild) a store.

## Run

```bash
python3 main.py --help
python3 main.py
python3 main.py --break search_index
python3 main.py --break postgres
```

Requires Python 3.10+ (stdlib only). Creates a `data/` folder next to `main.py` when needed.
