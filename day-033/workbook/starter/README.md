# Starter: Day 033

Turn rows into columns and measure analytical scans. Column store wins on single-column aggregate, row store competes on wide reads.

## Run

```bash
python3 main.py --help
python3 main.py
python3 main.py --wide
```

Requires Python 3.10+ (stdlib only). Creates a `data/` folder next to `main.py` when needed.
