# Starter: Day 050

Choose a replication architecture for a multi-region workload. Scores architectures against stated requirements.

## Run

```bash
python3 main.py --help
python3 main.py
python3 main.py --multi-write
python3 main.py --break
```

Requires Python 3.10+ (stdlib only). Creates a `data/` folder next to `main.py` when needed.
