# Starter: Day 046

Create, and then eliminate, reads that go backwards in time. Pinning eliminates backward-in-time reads.

## Run

```bash
python3 main.py --help
python3 main.py
python3 main.py --break
python3 main.py --pin
```

Requires Python 3.10+ (stdlib only). Creates a `data/` folder next to `main.py` when needed.
