# Starter: Day 027

Build immutable sorted segments and lookups. Adjust `--stride` to see sparse index hop vs in-segment scan cost.

## Run

```bash
python3 main.py --help
python3 main.py
python3 main.py --miss
python3 main.py --stride
```

Requires Python 3.10+ (stdlib only). Creates a `data/` folder next to `main.py` when needed.
